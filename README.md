# こころの記録 — CBT Journal

スマートフォンとPCで使える、サーバー不要のCBT（認知行動療法）記録アプリです。

## 使い方

1. `index.html` をモダンブラウザで開きます。
2. 初回だけ6文字以上のパスコードを設定します。
3. 「新しい記録」から出来事と認知を記録します。

PDFは、記録詳細の「PDFを作成」から開く印刷画面で、保存先を「PDFに保存」にしてください。カウンセラー記入欄を含み、アプリ内のカウンセラーフィードバック本文はPDFに出力されません。

## データと安全性

- 記録はブラウザのローカルストレージにAES-GCMで暗号化して保存されます。サーバーへの送信はありません。
- バックアップは設定画面からJSON形式で書き出し／読み込みできます。JSONバックアップは暗号化されていないため、安全な場所に保管してください。
- パスコードを忘れた場合は記録を復元できません。バックアップを定期的に作成してください。

## 無料での公開

静的ファイルのみで構成されているため、GitHub Pages、Cloudflare Pages、Netlifyなどの無料の静的ホスティングにそのまま配置できます。公開時はHTTPS環境で利用してください（ブラウザの暗号化APIを安全に使うためです）。

## PC・スマホ同期（Supabase）

1. Supabaseでプロジェクトを作成します。
2. SQL Editorで [`supabase-setup.sql`](supabase-setup.sql) の内容を実行します。
3. Project Settings → APIから **Project URL** と **anon public key** を確認します（`service_role` keyは絶対に使わないでください）。
4. アプリの「設定・データ管理」→「PC・スマホ同期」で、URL・anon key・メールアドレス・パスワードを入力してアカウントを作成します。
5. 最初の端末ではログイン後にクラウドへ保存します。別の端末では同じアプリ用パスコードを設定してから同じSupabaseアカウントでログインし、「クラウドの記録をこの端末へ取得」を押します。

クラウドに保存されるのはアプリ用パスコードで暗号化済みのデータです。端末間で同じアプリ用パスコードを使用してください。
