# こころの記録 — CBT Journal

スマートフォンとPCで使える、サーバー不要のCBT（認知行動療法）記録アプリです。

## 使い方

1. `index.html` をモダンブラウザで開きます。
2. 初回だけ6文字以上のパスコードを設定します。
3. 「新しい記録」から出来事と認知を記録します。

PDFは、記録詳細の「PDFを作成」から開く印刷画面で、保存先を「PDFに保存」にしてください。カウンセラー記入欄を含み、アプリ内のカウンセラーフィードバック本文はPDFに出力されません。

## 認知のゆがみ

記録画面では、認知のゆがみを11項目から複数選択できます。各項目の「？」を押すと、説明・気づきのサイン・例・対処のヒント・自分への問いかけが表示されます。サイドバーの「認知のゆがみ辞典」からは一覧で読めます。

完全主義（全か無か）／過度の一般化／心のフィルター／マイナス化思考／結論の飛躍（心の読みすぎ）／結論の飛躍（先読みの誤り）／拡大解釈と過小評価／感情的決めつけ／べき思考／レッテル貼り／個人化

選択内容は記録詳細とPDFにも出力されます。以前の自由記述は「ゆがみについてのメモ」として残ります。

## データと安全性

- 記録はブラウザのローカルストレージにAES-GCMで暗号化して保存されます。
- バックアップは設定画面からJSON形式で書き出し／読み込みできます。JSONバックアップは暗号化されていないため、安全な場所に保管してください。
- パスコードを忘れた場合は記録を復元できません。バックアップを定期的に作成してください。

## 無料での公開

静的ファイルのみで構成されているため、GitHub Pages、Cloudflare Pages、Netlifyなどの無料の静的ホスティングにそのまま配置できます。公開時はHTTPS環境で利用してください（ブラウザの暗号化APIを安全に使うためです）。

## PC・スマホ同期（Supabase）

1. Supabaseでプロジェクトを作成します。
2. SQL Editorで [`supabase-setup.sql`](supabase-setup.sql) の内容を実行します（Realtimeの設定も含みます）。
3. Project Settings → APIから **Project URL** と **anon public key** を確認します（`service_role` keyは絶対に使わないでください）。
4. アプリの「設定・データ管理」→「PC・スマホ同期」で、URL・anon key・メールアドレス・パスワードを入力してアカウントを作成します。
5. 2台目以降の端末では、同じアプリ用パスコードを設定してから同じSupabaseアカウントでログインしてください。

クラウドに保存されるのはアプリ用パスコードで暗号化済みのデータです。端末間で同じアプリ用パスコードを使用してください。

### 自動同期の動作

ログイン後は、次のタイミングで自動的にクラウドと同期します。

- 記録を保存・編集・削除した直後（約1秒後に送信）
- ロック解除の直後
- 他の端末が更新したとき（Supabase Realtime）
- 45秒ごと、およびアプリの画面に戻ったとき・オンラインに復帰したとき

画面右上（PCではサイドバー下部）のバッジで「同期済み／同期中／オフライン／確認待ち」を確認できます。⟳ を押すとその場で同期します。オフライン中の変更は、接続が戻ったときにまとめて送信されます。

### 競合したときの確認

同じ出来事を複数の端末から更新した場合は、上書き確認のダイアログが記録ごとに表示されます。

- **両方の端末で編集**：この端末の内容で上書き／クラウドの内容で上書き／両方を残す（クラウド版を別の記録として複製）
- **他の端末で削除された記録を編集していた**：削除を反映する／この端末の記録を残す
- **この端末で削除した記録が他の端末で編集された**：クラウドの記録を復元／削除したままにする

「あとで決める」を選ぶと、その回の送信は保留され、次の同期で再び確認します。競合していない記録は、確認なしでそのまま同期されます。

## データ形式について

各記録には更新日時（`updatedAt`）が付き、削除は削除履歴として90日間保持されます。これらは記録単位で競合を判定するために使われます。以前のバージョンで作成したデータは、初回のロック解除時に自動で移行されます。
